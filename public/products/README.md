# 产品图放置说明

## 怎么放

把白底产品图直接放进这个目录，文件名用**单个大写字母**（对应 12 个大类），扩展名支持 `.webp` `.jpg` `.jpeg` `.png` `.avif`。

```
public/products/A.webp   → A 防护服/手术衣类
public/products/C.png    → C 口罩类
public/products/E.webp   → E 帽/头套类
```

同一大类想放多张：`A-1.webp`、`A-2.webp`（取第一张作主图）。

## 规格建议

- 比例 1:1（正方形），建议 1200×1200 以上
- **纯白底**（#FFFFFF），产品居中，四周留约 8% 空白
- 无文字、无水印、无人像
- 格式优先 `.webp`（体积小），单张建议 < 200KB

## 对照表

| 字母 | 大类 |
|---|---|
| A | 防护服 / 手术衣类 |
| B | 隔离衣类 |
| C | 口罩类 |
| D | 手套类 |
| E | 帽 / 头套类 |
| F | 鞋套 / 靴套类 |
| G | 手术单 / 洞巾 / 包布类 |
| H | 医用敷料类 |
| I | 一次性无纺布日用品 / 美容 |
| J | 围裙 / 袖套类 |
| K | 医疗包类（组件打包） |
| L | 其他无纺布医疗 |

## 放完怎么办

不用改代码。重新构建即自动识别：

```bash
npm run build
```

构建前会自动扫描本目录并生成 `src/data/generated/product-images.json`。
